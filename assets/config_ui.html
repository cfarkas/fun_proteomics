3. Optional count filtering

Uncheck to turn low-count filtering off; threshold values are then ignored. All features with nonzero total counts are eligible for testing. All-zero features cannot be tested.

Applies to proteins, supporting peptides and optional gene comparisons. Modified-peptide thresholds are below. Excluded features stay in raw count tables.

Sparse modification counts

Recommended: edgeR small-count GLM with TMMwsp normalization. Each modification type is tested separately.

Low-evidence rows remain in count matrices and are listed in the filtering report. edgeRun and limma are comparison methods for sparse counts.

edgeRun options

Default/minimum: 100,000, in increments of 100. Higher limits increase computation. This is not a number of simulation iterations.

Normalization and model settings

edgeR and limma use spectral counts with TMM normalization. limma adds voom weights. Low-count filtering is optional and off by default. Dispersion estimation is automatic.

Each cohort and search mode is analyzed separately. At least two conditions and two independent replicates per condition are needed. Batch or paired-subject effects are not inferred.

Normalized and z-score matrices are exported whether or not DEPs are enabled.

6. Optional analyses

This DIA workflow runs global protein quantification. Phosphorylation, HLA, isoform and drug-interaction analyses are not included. Your DDA choices remain saved for DDA studies.

Choose any additional analyses. Low coverage does not fail the study: results include nonsignificant features, and tests with insufficient evidence are labeled in the output tables.

Gene-level counts and comparisons

Use peptides assigned unambiguously to one gene. Peptides shared between genes are excluded from these counts only; protein counts remain unchanged. These are proteomics measurements, not RNA expression.

Raw counts, normalized matrices and z-scores appear under Optional analyses → Gene counts. With differential analysis enabled, gene comparisons use the methods, reference condition, FDR and count filters selected in DEPs, with separate model fitting and FDR correction. Modified-peptide counts per gene follow this option too. If drug-interaction testing is enabled, this option also includes its gene-level tests, using the drug-interaction methods and FDR.

Immunopeptidomics

Optional dedicated workflow for HLA-enriched, undigested peptides measured by DDA-PASEF.

Choose Yes for HLA-enriched, undigested peptide samples. Choose No for ordinary global or phosphoproteomics samples.

Both classes use a 7–25 amino-acid search. Class selection labels the report and sets the length range of the sequence export for external binding prediction.

Dedicated HLA search preset
  • Nonspecific digestion; no fixed cysteine modification.
  • Variable oxidation, protein N-terminal acetylation and cysteinylation.
  • DDA search with MSBooster / Percolator; 1% PSM FDR. Peptide and protein FDR are not restricted to 1%.
  • IonQuant enabled; match-between-runs off.

This selects DDA only and replaces the global or phosphorylation search settings. DEPs methods, comparisons and optional low-count filtering apply to peptide spectral counts only.

Results include peptide counts, sample summaries, peptide-length distributions and sequences for external HLA binding prediction. Binding prediction and allele assignment are not run here.

Based on Benchmarking Software for DDA-PASEF Immunopeptidomics, adapted to the installed FragPipe 24 tools. Validate with representative HLA-enriched samples before scientific use.

Peptide and isoform evidence

Report peptide detection by condition, sequence coverage and evidence that distinguishes protein isoforms. Select a FASTA containing isoform sequences in Database & tools. Shared peptides stay ambiguous; insufficient coverage is reported. HLA peptides describe source-sequence evidence rather than source-protein expression.

Drug experiments

Use DEPs to compare individual drug treatments with your control. Combination-interaction testing is inactive for single-drug studies.

Test whether the combination differs from the expected combined effects of the individual drugs. This uses proteomic measurements; it does not calculate a cell-viability synergy score.

The contrast is combination − drug A − drug B + control on a log2 scale, using TMM-normalized spectral counts. Zero means the combination follows the multiplicative expectation from the single drugs. Each selected method has separate results and Benjamini–Hochberg FDR for each feature type and search mode.

Interaction methods (choose one or more)

Uses precision-weighted log2 counts and moderated t-tests. Reports interaction effects, 95% confidence intervals, p-values and FDR. Empirical Bayes moderation is not a fully Bayesian interaction posterior.

Simulates negative-binomial counts while retaining the fitted single-drug effects and setting interaction to zero. Compares observed and simulated likelihood-ratio statistics to calculate empirical p-values and FDR. Fitted dispersion and normalization are held fixed, so this is an approximate parametric bootstrap.

The smallest possible p-value is 1 / (simulations + 1): 9,999 simulations gives 0.0001. More simulations improve p-value resolution but take longer; limited resolution can prevent FDR discoveries in large tables. Results include simulation uncertainty. Workers are capped by the study's threads, and the seed makes results reproducible across worker counts.

Matching doses and treatment times have not been confirmed. The analysis will run as an exploratory combination contrast; dose or timing differences can affect the result.

Requires four different conditions and at least two independent biological replicates per condition. Low counts are included; results with insufficient evidence are retained and labeled. This analysis runs even when DEPs is off. HLA-enriched studies test peptides only.
