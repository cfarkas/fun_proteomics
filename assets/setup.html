Optional: import sample groups or choose an Excel sheet

A table with sample_id and condition can fill in your groups. Raw-data tables also need raw_path. Otherwise, assign groups below.

Example samples.csv — sample IDs must match the samples in your matrix:

sample_id,condition
C1,Control
C2,Control
T1,Treatment
T2,Treatment

Example samples.csv for raw data:

sample_id,condition,raw_path
C1,Control,raw/C1.d
C2,Control,raw/C2.d
T1,Treatment,raw/T1.d
T2,Treatment,raw/T2.d

Replace the example paths with your .d folders. Relative paths start from the selected raw-data folder, or from the CSV folder if no raw-data folder is selected. Full paths also work.

Choose a sheet by name only if your workbook contains several protein quantity sheets.

Assign and name your samples

Drag detected samples into a condition, or use the dropdown on each card. Drag between columns to correct an assignment, or back to Unassigned to exclude a sample. Edit sample and condition names as needed.

Only assigned samples enter the matrices, benchmarks and comparisons. Conditions are never inferred from filenames. Source filenames and columns remain linked when you rename a sample.

Review & save

Result locations
Choose a project folder to see where results will be saved.

Every pair of conditions will be compared at protein and available gene levels.

Use independent samples for different patients. For matrix data measured across conditions in the same donors, select paired comparisons below. Matrix imports require one quantity per donor/condition. For BAF, give technical injections the same biological sample ID on their cards.

Import this column with your sample table, or enter donor IDs on the sample cards in step 1. Matching uses these IDs, never filenames.

GN= annotations supply missing gene symbols. DIA needs target-only FASTA; DDA needs a validated search FASTA with contaminants and matching rev_ decoys.

Use the pinned versions listed in the installation guide. The advanced raw editor also prepares FASTA databases and supports DDA+.

The original run supplies its sample design, input files and statistical settings. Reuse checks happen before execution.

Optional analysis settings

Reports shared proteins, pipeline-only proteins, service-only proteins, and the net difference per sample and overall.

P-value mode keeps limma P values. Empirical-normal mode recalibrates t statistics; review its null diagnostics and separate P-value column.

An imported native configuration supplies its own sample design and comparison settings.
