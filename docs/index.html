Discover the samples, review the four condition columns, confirm the replicate design, then save and run. This uses real quantified data and does not repeat a raw spectrum search.

Step-by-step guide and expected outputs

2. Set up your analysis

Choose one launch method. --project is your output folder. setup --outdir is equivalent. Use a new project for a new analysis.

A) Interactive settings

fun_proteomics setup --project /data/my-study
  1. Choose a matrix, raw-data folder or previous run, and review the output folder.
  2. Click Discover samples, then drag sample cards into condition columns. Add or rename conditions; move exclusions to Unassigned. A sample table can prefill assignments.
  3. Choose independent samples or paired matrix/BAF comparisons with donor IDs. Four conditions produce six condition pairs at each feature level.
  4. Click Save configuration and check, then Run / continue analysis.
  5. Open Results or Matrices · CSV & TSV in the same page.

Keep the terminal open during setup. Browse paths refer to the computer running the analysis.

Inputs, donors, technical injections and SSH browser access

B) Terminal questions

fun_proteomics setup --terminal --project /data/my-study --run

Answer the questions about inputs, conditions, replicate design and output folder. This works over SSH. Omit --run to save and review first.

C) Full command-line options

fun_proteomics setup --non-interactive --project /data/my-study \
  --mode matrix --matrix /data/proteins.csv --samples /data/samples.csv \
  --independent-samples --normalization none \
  --cpus 8 --memory-gib 32 --run

For paired matrix/BAF data, replace --independent-samples with --subject-column donor. Add --service-matrix /data/provider.tsv for a matched service benchmark.

Check and run saved settings
fun_proteomics check --config /data/my-study/config/run.json
fun_proteomics run --config /data/my-study/config/run.json
