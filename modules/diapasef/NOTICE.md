# Distribution notes

This repository contains project source, configuration examples, sample tables
and tests. It does not redistribute the DIA-NN binary, native libraries, Python
wheels, raw measurements, input FASTAs, service matrices or study abundance results.

The environment installer downloads the official DIA-NN Academia distribution
or uses a supplied local cache. Its upstream terms apply; retain the notices
distributed with that software. See the [official DIA-NN project](https://github.com/vdemichev/DiaNN).
Nextflow and the Python packages retain their own upstream licenses.

Original project code and documentation use the MIT license in the repository
LICENSE. That license does not change ownership or distribution terms for
third-party software.
